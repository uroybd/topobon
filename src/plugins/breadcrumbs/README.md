# Breadcrumbs

Shows the note's folder path above its title.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/breadcrumbs/` in your garden repo.

## Settings

- **Home label** — First crumb, linking to the home page. Leave empty to hide it.
- **Separator**
